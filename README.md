# كورال الأنبا كاراس Ⲁⲃⲃⲁ Ⲕⲁⲣⲁⲥ

تطبيق إدارة الكورال (Capacitor + Firebase) — كنيسة الأنبا كاراس والأنبا إبرام بالخصوص.

## الميزات
- الكورالات: ابتدائي، إعدادي، ثانوي، عام، إعداد قادة. وفي التسجيل يختار الشخص «خادم» أو أحد الكورالات.
- كل مخدوم وخادم له حساب. الخادم يقدر كمان يضيف مخدومين (الاسم، التليفون، الميلاد، الصورة).
- حضور بالـ QR (المخدوم يمسح كود الحدث، أو الخادم يمسح كود المخدوم) وحضور يدوي لمن ليس معه موبايل.
- نقاط: فتح التسجيل قبل البروفة بـ 15 د (حتى 30)، 5 نقاط في الميعاد، خصم نقطة كل 5 د تأخير، صفر بعد 30 د، قفل بعد ساعة (والخادم يضيف يدويًا). كل الأرقام قابلة للتعديل من الإعدادات.
- الخادم يخصم/يضيف نقاط والمخدوم يصله إشعار بالسبب.
- إشعارات: أعياد الميلاد مع نسبة الحضور (للافتقاد)، تقرير الثلاثاء 9 صباحًا، ومواعيد البروفات والحفلات.
- شاشة «الرولز» داخل التطبيق، وست خلفيات أرثوذكسية (سماء وكنيسة، الهيكل، شموع وصليب، بخور، أيقونة، تسبيح) بآيات التسبيح من ترجمة فان دايك.

## الجديد في الإصدار 4.0.0 (دمج مميزات Silent Monk)
الترانيم والمجلدات والسلة ومشغل الصوت • التصويت • سجل الحضور والغياب والإحصائيات • لوحة الشرف للمنتظمين • بروفة أسبوعية ثابتة • إعدادات التذكيرات • إشعار التحديثات.
التفاصيل: `FEATURE_MERGE_AUDIT.md` و`IMPLEMENTATION_REPORT.md`. **قبل الاستخدام انشر `firestore.rules`** — الخطوات في `FIREBASE_MIGRATION.md`.

## التشغيل
1. اتبع `FIREBASE_SETUP.md` (3 خطوات في لوحة Firebase، بدون Cloud Functions ولا خطة مدفوعة).
2. ارفع المشروع على GitHub؛ الـ APK يُبنى تلقائيًا من تبويب Actions.
3. محليًا: `npm install && npm run build`.

## نسخة الكمبيوتر (Windows)
تُبنى تلقائيًا من `.github/workflows/build-windows.yml` (تبويب Actions ← Build Windows App ← Artifacts).
تفتح نفس التطبيق ونفس Firebase في نافذة على الكمبيوتر. ملف `AbbaKarasChoir ... .exe` (portable) يشتغل بدون تثبيت.
